**【要確認】のところは、アカウント主が決めるまで勝手に埋めない。**（「案」は、たたき台としてチームが書いたもの）

## 2. このアカウントで書いてはいけないこと

### 事実の確かめ方
1. **エピソード・名言・数字は、確かめられたものだけ使う。**
   - 使ってよい出典：本人の発言（公式インタビュー・著書・本人の公式アカウント）、事務所や番組の公式サイト、新聞・テレビなどの報道機関。
   - 使わない出典：うわさ、まとめサイト、SNS の書き込み、出典のない「〜らしい」。
   - 出典はページ名と URL（本なら書名）を、台本の下などに控えておく。
   - 確かめられないものは **【要確認】** を付け、確かめるまで投稿に出さない。
2. **本人が言っていない言葉を、本人の言葉として書かない。** 名言は言いかえず、そのまま引用して出典を書く。セリフや心の声を作らない。
3. **話を盛らない。** 「〇〇時間練習した」などの数字を大きくしない。「〜だから成功した」と言い切らない。
4. 事実を Web で調べるのも、アカウント主の許可が出てから（`CLAUDE.md` のとおり）。

### 人へのふるまい
5. **悪口・からかい・ゴシップを書かない。** だれかを下げて、だれかを上げる比べ方もしない。
6. **プライベートにふみこまない。** 恋愛・家族・病気・住所・学歴の細かいことなど、本人が広く公にしていないことは扱わない。
7. **亡くなった方・事件・病気・炎上の話は、扱う前にアカウント主に確認する。**
8. **努力を押しつけない。** 「努力しない人はダメ」「〜すべき」のような言い方はしない。

### 権利・なりすまし
9. **芸能人の写真・番組や映画の画面・CDジャケット・ロゴは使わない。**（肖像権・著作権のため）写真は、顔や読める文字が映らない無料素材を使う。
10. **本人や事務所の公式アカウントに見える作り方をしない。** 本人のふりをしない。

## 3. アフィリエイト投稿（チームの担当）

通常の投稿はアカウント主が作る。チームは、商品を紹介して紹介料をもらう「アフィリエイト投稿」を作る。

### 形（案。決まったら書きかえる）
- 芸能人の努力の話（雑学） → その努力に関係する商品を1つ紹介 → 「プロフィールのリンク／ストーリーズのリンクから見られます」
- 雑学の部分がメイン。売りこみは最後に短く。見た人が「話がおもしろかった」で終われるようにする
- 紹介する商品：【要確認】（案：本人の著書・自伝、本人が出ている作品、努力・習慣づくりの本や道具）
- 使うアフィリエイトのサービス：【要確認】（Amazonアソシエイト・楽天アフィリエイト・A8.net など）
- リンクを置く場所：【要確認】（Instagram の投稿文のリンクは押せないため、プロフィールのリンクかストーリーズのリンクスタンプ）

### 書いてはいけないこと（アフィリエイト）
1. **広告だとはっきりわかるようにする。** 動画の最初の画面と投稿文の1行目に「PR」または「広告」と入れる（ステマ規制〈景品表示法〉のため）。かくしたり、小さすぎる文字にしたりしない。
   - サービスごとに決まった書き方がある（例：Amazonアソシエイトは「Amazonのアソシエイトとして適格販売により収入を得ています」の表示が必要）。使うサービスが決まったら、その公式の決まりで確かめて【要確認】をはずす。
2. **芸能人が使っている・すすめていると、確かめずに書かない。** 「〇〇愛用」「〇〇も使っている」は、本人の発言・公式などの出典があるときだけ。なければ書かない。
3. **芸能人が商品を応援しているように見せない。** 本人の名前や話で、関係のない商品を売らない（パブリシティ権のため）。本人の著書・出演作品なら紹介してよい。
4. **アカウント主が使っていない商品を「使ってよかった」と書かない。** 使った感想は、アカウント主が言ったものだけ。
5. **効果を言い切らない。** 「これで必ず続く」「人生が変わる」などは書かない。
6. **値段・在庫・セール情報は書かない**か、書くなら確かめた日を添えて【要確認】にする（すぐ変わるため）。
