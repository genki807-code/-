# 最後まで見られる編集（saigo-made-henshu）

台本をもとに、最初の1秒で止まってもらい、最後まで見てもらえる編集の設計図を作ります。アカウント主（または組み立てる人）が、編集アプリで上から順にそのまま作業できる形にします。

## 手順

### 1. 読む
- フォルダのいちばん上の `CLAUDE.md`（共通ルール）を読む。
- 担当するアカウントのフォルダの `アカウント設定.md` と `引き継ぎメモ.md` を読む（どのアカウントの仕事か分からないときは、作業を始めずに確かめる）。
  - **アカウントごとの見た目の決まり（テロップの色・文字の大きさ・音の有無・最後の画面の言葉など）が、このスキルとちがうときは、アカウントの決まりを優先する。**
  - 例：メンタルは、白い文字＋黒いふち＋ピンクの帯・句読点なし・0秒から文字が出ている・BGMや効果音は使わない（声なし・音なし）。
- `<アカウント>/02_台本/` の、その日の台本（いちばん新しい `_v` の版）を読む。

### 2. 最初の1秒の画面を決める
- **最初の1秒で見せる画面と、そこに出す大きな文字**を決める。
  - 文字は台本のフックの言葉をそのまま使う（短く・大きく・1秒で読める量）。
  - 0秒の最初のコマから文字を出す（フェードで後から出さない）。
  - 写真や映像は、1秒で場面がわかるものにする。
- 決めた理由を1〜2行で書く。

### 3. カットごとに分けて表にする
- 台本を、画面が切りかわる区切り（カット）ごとに分けて表にする。
- **1つのカットが長くなりすぎないようにする**（目安：1カット 2〜5秒。長くなるときは、同じ写真でも寄る・場所を変えるなど、動きを入れる）。
- カットごとに開始〜終了の秒数を書き、最後に合計の秒数を書く。

### 4. カットごとに書くこと
カットごとに、次の4つを書く。

| 書くこと | 中身 |
|---|---|
| 画面に出す文字（テロップ） | 台本の言葉。1行の長さと行数・表示する秒数（読み切れる長さか） |
| 強調する言葉 | 色を変える・大きくするなどする言葉（1カットに1つまで） |
| 差しこむ画像や画面の録画 | 使う写真・映像・画面の録画と、切り抜く場所や寄り方 |
| 効果音を入れる位置 | 入れる秒数と音の雰囲気。入れないカットは「なし」。音を使わないアカウントは全部「なし」 |

### 5. 最後の画面
- 最後の画面で、**見た人にしてほしいこと（保存・コメントなど）**が伝わるようにする。
  - 文字だけで伝わるように書く（音がなくても分かる）。
  - アカウントで決まっている締めの言葉（例：メンタルの保存のお願い＋フォローのお願い）があるときは、それを使う。
  - 読み切れる時間（目安 3〜4秒）をとる。

### 6. 上から順に並べる
- 編集アプリでそのまま作業できるように、**作業する順番（上から順）**に並べる。
  1. 全体のメモ（長さ・画面の比率 9:16・文字の見た目・音の有無）
  2. 使う素材の一覧（写真・映像のファイル名）
  3. カットの表（0秒から順）
  4. 最後の画面
  5. 書き出す前のチェック（下の「書き出す前に見ること」）

### 7. 保存する
- `<アカウント>/03_編集/【日付】_【企画名】_編集の設計図.md` に保存する（例：`メンタル/03_編集/2026-11-18_家事が回らない_編集の設計図.md`）。
- 直したときは上書きせず `_v2` `_v3` を付けて新しく保存する。
- 保存した場所（ファイルのパス）を必ず伝える。
- 投稿に出す前に、checker に回す（leader が回す）。

## 設計図の形（見本）

```
# 編集の設計図：【企画名】（担当：editor）

- もとにした台本：02_台本/…
- 長さ：約〇秒（〇カット）・9:16
- 文字の見た目：…（アカウントの決まり）
- 音：…（BGM・効果音のあり／なし）

## 最初の1秒
- 画面：…
- 大きな文字：…
- 理由：…

## 使う素材
| 素材 | ファイル | メモ |
|---|---|---|

## カット表（上から順に作業）
| カット | 秒数 | 画面（画像・映像） | テロップ | 強調する言葉 | 効果音 |
|---|---|---|---|---|---|
| 1 | 0〜3 | … | … | … | なし |

## 最後の画面
- 文字：…（してほしいこと）
- 秒数：…

## 書き出す前に見ること
- [ ] 0秒から文字が出ている
- [ ] どのテロップも表示時間内に読み切れる
- [ ] 人の顔・ロゴ・読める文字が映っていない（アカウントの決まりに合わせる）
- [ ] 点滅・急な大きな音・強すぎる色がない

## 【要確認】
- …
```

## 守ること
- **アカウント主が言っていない実績・数字・体験は書かない。** 必要なときは【要確認】と書いて残す。
- 見ていて疲れる作りにしない（点滅・急な大きな音・強すぎる色は使わない）。
- 曲や効果音を名前で指定するときは、使えるか（著作権・Instagram で使えるか）を【要確認】にする。
- 写真・映像は、無料で商用OKのものか、アカウント主が用意したものだけ。芸能人の写真・番組の画面・ロゴは使わない（芸能人雑学）。
- ほかのアカウントの見た目の決まりを当てはめない。
- Instagram などの SNS へのログイン・投稿・自動での情報集めはしない。
