# 伸びる台本を書く（nobiru-daihon）

選ばれた企画から、最初の2秒で「自分のことだ」と思ってもらい、最後まで見てもらえるリール台本を書きます。

## 手順

### 1. 読む
- フォルダのいちばん上の `CLAUDE.md`（共通ルール）を読む。
- 担当するアカウントのフォルダの `アカウント設定.md` と `引き継ぎメモ.md` を読む（どのアカウントの仕事か分からないときは、書き始めずに確かめる）。
  - **アカウントごとの決まり（見た目・型・言葉・CTA の言葉など）が、このスキルとちがうときは、アカウントの決まりを優先する。**
  - 例：メンタルは、画面1をマイナスの気もちから入る・句読点なし・最後は保存とフォローの決まった言葉。
- `<アカウント>/01_リサーチ/` の、選ばれた企画を読む。
- `<アカウント>/02_台本/` の最近の台本をざっと見て、言葉のかぶりを避ける。

### 2. 冒頭のひとこと（フック）を3案出す
- **最初の2秒で「自分のことだ」と思ってもらえる言い方にする。**
  - 見る人の頭にそのまま浮かんでいそうな言葉（心の声）・だれにでもある場面・短い言葉にする。
  - 1行目だけで、何の話か分かるようにする。
- 3案を表にして、それぞれの良いところ・気になるところを1行ずつ書き、おすすめを1つ選ぶ。
- 責める言い方・不安をあおる言い方にはしない。

### 3. 結論を先に言い、手順や理由は3つ以内
- フックのすぐあとに、共感 → 結論（いちばん伝えたいこと）を言う。
- そのあとに、手順・理由・コツを **3つ以内** でまとめる（①②③）。
- 1つのコツは1つの行動にしぼる。「これで治る」「絶対」などの言い切りはしない。

### 4. 1行は短く、話し言葉で・30〜60秒
- 1行は短く（目安：1行15文字くらいまで）。話しかけるような言葉にする。
- 声に出して読み上げて、**30〜60秒** におさまる長さにする。画面ごとの秒数を書き、合計の秒数も書く。

### 5. 見た人にしてほしいことは1つだけ
- 最後に、「保存」や「コメント」など、見た人にしてほしいことを **1つだけ** 入れる。
  - ただし、アカウントで決まっている締めの言葉（例：メンタルの「保存のお願い＋フォローのお願い」）があるときは、そちらを優先する。

### 6. 撮影するもの・画面に出すもののメモ
- 台本の下に「撮影するもの・画面に出すもの」のメモをつける。
  - 画面ごとに：撮るもの（または使う写真）・画面に出す文字・気をつけること（顔・ロゴ・読める文字が映らないか など）。

### 7. 保存する
- `<アカウント>/02_台本/【日付】_【企画名】.md` に保存する（例：`メンタル/02_台本/2026-11-18_家事が回らない.md`）。
- 直したときは上書きせず `_v2` `_v3` を付けて新しく保存する。
- 保存した場所（ファイルのパス）を必ず伝える。
- 投稿に出す前に、checker に回す（leader が回す）。

## 台本の形（見本）

```
# リール台本：【企画名】（担当：script）

- 投稿：【日付】20:00
- もとにした企画：01_リサーチ/…
- 長さ：約〇秒（〇画面）

## フック3案
| 案 | ことば | 良いところ | 気になるところ |
|---|---|---|---|
| A（おすすめ） | … | … | … |
| B | … | … | … |
| C | … | … | … |

## 台本（フックは A で書いた）
| 画面 | 流れ | 秒数 | ことば |
|---|---|---|---|
| 1 | フック | 0〜3 | … |
| 2 | 共感 | … | … |
| 3 | 結論 | … | … |
| 4〜6 | ①②③ | … | … |
| 7 | 締め＋してほしいこと1つ | … | … |

## 撮影するもの・画面に出すもの
| 画面 | 撮るもの（写真） | 画面に出す文字 | 気をつけること |
|---|---|---|---|

## 【要確認】
- …
```

## 守ること
- **アカウント主が言っていない実績・数字・体験は書かない。** 必要なときは【要確認】と書いて残す。
- **ほかの人の台本の言い回しを、そのまま使わない。** 伸びている投稿は「言い方の型」だけを参考にし、言葉は自分で書く。
- `CLAUDE.md` と `アカウント設定.md` の「書いてはいけないこと」を守る（メンタルでは、診断・服薬・治療を断定しない・病名や症状の話にしない）。
- Instagram などの SNS へのログイン・投稿・自動での情報集めはしない。
