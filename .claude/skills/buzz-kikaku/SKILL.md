# バズる企画を出す（buzz-kikaku）

伸びている投稿の「伸びている理由」を分けて考え、このアカウントのジャンルとコンセプトに合わせた企画を5つ出します。

## はじめに
- フォルダのいちばん上の `CLAUDE.md`（共通ルール・やらないこと）と、担当するアカウントのフォルダの `アカウント設定.md`（ジャンル・コンセプト・届けたい相手・一人称・口調・書いてはいけないこと）を読む。
- `<アカウント>/01_リサーチ/` の過去の企画と、`<アカウント>/08_分析/` の最新の振り返り（あれば）も読み、ネタかぶりを避ける。

## 手順

### 1. 伸びている投稿のメモを読む
- `<アカウント>/01_リサーチ/` にある、アカウント主が集めた「伸びている投稿のメモ」をすべて読む。
  - ファイル名に「メモ」が入っているもの（例：`2026-10-23_伸びている投稿メモ.md`）を探す。
  - 見つからないときは、`<アカウント>/01_リサーチ/` のファイルを見て、それらしいものがないか確かめる。
- **メモが足りないとき（ない・少ない・古いなど）は、Web で調べる前に、必ずアカウント主に「Web で調べてよいか」を聞く。**
  - アカウント主に直接聞けないとき（leader などから呼ばれたとき）は、ここで作業を止める。そして「メモが足りないので、Web で調べてよいか聞いてください」と、何が足りないかを添えて報告する。
  - 許可が出たときだけ Web で調べる。依頼の中に「Web で調べてよい」とはっきり書かれていれば、許可が出たものとする。
  - Web で調べるときも、Instagram などの SNS にログインしたり、SNS のページを自動で巡回して集めたりはしない。
  - 調べたページは、ページ名と URL を控えておく。
- 許可が出なかったときは、メモと一般的な知識だけで進め、「メモが少ないため根拠が弱い」とファイルに書く。

### 2. 伸びている理由を3つに分ける
メモの投稿ごとに、伸びている理由を次の3つに分けて書き出す。

| 投稿（メモのどれか） | だれの | どんな悩みに | どんな言い方で |
|---|---|---|---|
| 例：メモの1つめ（メンタル） | 働く20代の繊細さん | 休んだ日に自分を責めてしまう | 心の声をそのまま見せて共感 → 言い換え |

- 「どんな言い方で」には、文章そのものではなく、言い方の型を書く（例：「心の声→言い換え」「〇〇な人の特徴3つ」「やめてよかったこと」）。
- 最後に、メモ全体に共通している点を3行くらいでまとめる。

### 3. 企画を5つ出す
- `アカウント設定.md` のジャンルとコンセプトに合うものにする。
- `アカウント設定.md` の届けたい相手の悩みから考える。
- 芸能人雑学のアカウントでは、確かめられるエピソードだけで企画を立てる。確かめていないものは【要確認】を付ける。
- 手順2で見つけた「だれの・どんな悩みに・どんな言い方で」の型を使い、中身はこのアカウントのものとして新しく考える。

### 4. 企画ごとに3つをつける
1つの企画ごとに、次の項目を書く。

- **タイトル案**
- **形式**（リール／カルーセル／ストーリーズ）
- **だれの・どんな悩みに・どんな言い方で**（手順2のどの型を使ったか）
- **冒頭のひとこと**：最初の1〜2秒で「私のことだ」と思ってもらう言葉
- **見せる場面**：画面に映すもの・場面のイメージ（人の顔を映さなくても作れる案だと、なおよい）
- **保存したくなる理由**：あとで見返したくなる中身（すぐ試せるコツ、言われたかったひと言など）

### 5. ◎○△をつけて、おすすめを決める
- 5つすべてに ◎（いちばんおすすめ）・○（よい）・△（今回は見送り候補）をつける。◎は1つだけ。
- 次の点で比べる：
  - コンセプトに合っているか
  - 冒頭で止まってもらえるか
  - 保存したくなるか
  - 過去の投稿とかぶっていないか
  - 無理なく作れるか
- いちばんのおすすめと、その理由を書く。

### 6. 保存する
- 保存先：`<アカウント>/01_リサーチ/【日付】_企画.md`（例：`<アカウント>/01_リサーチ/2026-10-30_企画.md`）
- 同じ名前のファイルがすでにあるときは、上書きせず `_v2` `_v3` を付けて保存する。
- 保存したら、保存した場所（ファイルのパス）を伝える。

## 保存するファイルの形

```
# 企画：【日付】（担当：research／スキル：buzz-kikaku）

## 読んだもの
- 01_リサーチ/〇〇.md（アカウント主のメモ）
- （Web で調べた場合）ページ名：URL（見た日）

## 伸びている理由（だれの／どんな悩みに／どんな言い方で）
（手順2の表と、共通している点）

## 企画5つ
### 企画1：タイトル案 ◎
- 形式：
- だれの・どんな悩みに・どんな言い方で：
- 冒頭のひとこと：
- 見せる場面：
- 保存したくなる理由：
（企画2〜5も同じ形）

## いちばんのおすすめ
企画〇：理由

## 【要確認】
```

## 守ること
- **ほかの人の投稿の文章を、そのまま写さない。** メモに書かれた文章・タイトル・言い回しは、そのまま企画に使わない。参考にするのは「だれの・どんな悩みに・どんな言い方で」という型だけにして、言葉は自分で新しく考える。
- **数字や事実を書くときは、どこで見たかを書く。**
  - 例：「（アカウント主のメモ：2026-10-23_伸びている投稿メモ.md より）」「（ページ名：URL）」
  - どこで見たか書けないものは書かないか、【要確認】を付ける。
- アカウント主が言っていない実績・数字・体験は書かない。
- 病気や症状について断定しない。不安をあおる・責める言い方の企画にしない。
- 他のアカウント名や個人を、悪く言ったり、からかったりする企画にしない。
