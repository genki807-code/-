## 3. 間に合わせるための目安と、作り置き（ストック）の考え方（案・【要確認】）

### 毎日1本の現実
いまの流れ（research → script → editor → thumbnail → caption → stories → checker → leader）は、10/27「不機嫌」で、企画から完成まとめまでに数日かかっています。さらに、素材探し・編集・表紙づくりはアカウント主の手作業です。**毎日1本を、その日ごとに一から作るのは、チームにもアカウント主にも追いつかない**と考えています。

### 何日前までに何を決めると間に合うか（目安）
投稿する日を「当日」としたときの目安です。体調や作業の速さで変わるので、合わなければ直します。

| いつまでに | 決めること・できていること | だれ |
|---|---|---|
| **5日前** | テーマを決める（候補から選ぶ） | アカウント主 → leader |
| 4日前 | 台本 | script |
| 3日前 | 編集設計図・サムネ案・キャプション（ストーリーズをつけるならストーリーズも） | editor・thumbnail・caption・stories |
| 2日前 | checker の OK → leader の完成まとめ | checker・leader |
| **1日前** | 素材探し・編集・表紙づくり・「0秒チェックリスト」の A・B | アカウント主 |
| 当日 21時 | 自分の手で投稿 | アカウント主 |

- この目安だと、**今日（10/24）テーマが決まれば、いちばん早くて 10/29（木）に間に合う**計算です。10/28（水）は、今日の時点ですでに目安より短くなっています【要確認：10/28 をどうするか】。
- 文字の部分（台本〜キャプション）は、テーマが決まれば何本かまとめて作ることもできます。いちばん時間がかかるのは、**アカウント主の編集の作業**と、**checker を通すところ**だと考えています。

### 作り置き（ストック）の考え方
- **テーマはまとめて決める**：1本ずつではなく、たとえば週に1回、次の数日分のテーマをまとめて決めると、チームが先回りして作れます【要確認：何日分ずつ決めるか】。
- **編集はまとめて作る「作り置きの日」**：調子のいい日に、2〜3本ぶんの素材探し・編集をまとめて進めておくと、しんどい日の助けになります。作り置きの日を週の何曜日にするかは【要確認】。
- **ストックを何本持っておくか**：投稿できる状態の完成版を、いつも数本（例：2〜3本）持っておくと、体調が悪い日にも新しく作らずに出せます。何本を目標にするかは【要確認】。
- **同じ作り方をくり返す**：10/23・10/27 と同じ「声なし・文字だけ・約40秒・顔なしのフリー動画」の形をそろえると、毎回の編集が軽くなります。
- **ストックが切れた日のこと**：毎日投稿のルールでも、体調の悪い日やストックがない日をどうするか（休む／ほかの形にする など）を、先に決めておくと安心です【要確認】。休んだ日を、次の日に2本出して取り戻す必要はないと考えています。
- 作り置きしたものも、投稿の前に checker を通します。作り置きは「できたらラッキー」くらいで大丈夫です。

### ストーリーズを毎日つけるか【要確認】
- 10/23・10/27 はリール1本にストーリーズ4枚をつけています。毎日つけると、stories・checker の作業と、アカウント主が1日に何回も出す手間が増えます。
- 毎日つける／リールのシェア1枚だけにする／決めた曜日だけ4枚にする、などから、アカウント主に選んでほしいです。
