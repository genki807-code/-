# アカウント設定：メンタル

このアカウントの仕事をするときは、`CLAUDE.md`（共通ルール）とこのファイルの両方を守る。
決まったことの細かいところ（動画の見た目・次にやることなど）は `メンタル/引き継ぎメモ.md` を見る。

## 1. 発信の軸

| 項目 | 内容 |
|---|---|
| ジャンル | メンタル × 繊細さん、精神疾患者 |
| コンセプト | 繊細さん、精神疾患者でも生きやすくする |
| 届けたい相手 | 働く20〜30代の繊細さん（HSP気質で、職場の人間関係や疲れやすさに悩んでいる人。うつ・不安障害などで通院中の人も含む） |
| 一人称 | 私 |
| 口調 | です・ます調を基本に、ときどきやさしく語りかける |
| 投稿日 | 毎日 20時・リール1本（10/30 に21時から変更）（アカウント主が自分の手で投稿する。予約投稿・自動投稿はしない） |

### 口調の例
- ○「疲れやすいのは、あなたが弱いからじゃないんです。」
- ○「それ、あなたのせいじゃないよ。今日は休んで大丈夫です。」
- ×「甘えるな」「気にしすぎ」「〜すべき」（責める・押しつける言い方）
- ×「絶対に治る」「これで解決」（言い切り・誇張）

## 2. このアカウントで書いてはいけないこと

1. **通院歴・診断名・体験談を作らない。**（アカウント主が言ったものだけ）
2. **医療行為の代わりになる言い方をしない。**
   - 診断・服薬・治療について断定しない（「それはうつ病です」「薬はやめていい」などは書かない）。
   - 必要に応じて「つらさが続くときは、医師や専門の相談窓口に相談してください」と添える。
   - 相談窓口の名前・電話番号を書くときは、必ず **【要確認】** を付け、公式情報で確かめてから使う。
3. **不安をあおる・傷つける表現をしない。**
   - 自傷・自殺の方法や詳しい描写は書かない。
   - 特定の病気や人を笑いもの・悪者にしない。
4. **見ていて疲れる作りにしない。** 点滅・急な大きな音・強すぎる色は避ける。
