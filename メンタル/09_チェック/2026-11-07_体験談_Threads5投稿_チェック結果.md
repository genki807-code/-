## 投稿ごと

### 1：今の気もち — OK
- 体験はアカウント主の言葉どおり（11/7）。「元気な投稿ばかりじゃなくて」「ここに置いておきたくて」は気もちの書きそえで、新しい出来事は足していない

### 2：音がつらい日 — OK（直すとより安全）
- 該当：「今は聴覚過敏があって／音にとても疲れやすいです」
- 「音にとても疲れやすい」はアカウント主の言葉ではない言いかえ。言った言葉に近づけると安全
- 直し案：
  ```
  私の場合
  今は聴覚過敏が起こったりしていて
  すっごくつらいです
  ```
- 「耳を休ませる時間を少しだけ作ってあげてください」はやさしいすすめで、押しつけではないのでOK

### 3：理由のわからない不安 — 要修正
- 該当：「何かあったわけじゃないのに／不安が止まらない日」→「私も今／不安感が強くなっていて／しんどい日が続いています」
- 問題1：「私も」でつながるので、アカウント主の不安も「何もないのに出ている」ように読める。アカウント主はそう言っていない（作った体験になる）。また、アカウント主は「適応障害で」と言っているので、原因についての読まれ方がずれる
- 問題2：「しんどい日が続いています」の「続いている」は言っていない（言ったのは「すっごくつらい」）
- 直し案（「私も」をやめて、言った言葉にそろえる）：
  ```
  何かあったわけじゃないのに
  不安が止まらない日

  私は今
  適応障害で不安感が強くなっていて
  すっごくつらいです
  ```
  （もしくは、見出しと1〜2行目を「不安が強い日」など、理由のある・なしにふれない形にする）
- ほかの行（「気づくだけでじゅうぶんがんばっています」「今日を終えられたら花まる」）はOK

### 4：休むのがこわかった — 要修正
- 該当1：「前に適応障害がひどかったとき／休むのがこわくて／休んだら罪悪感でいっぱいでした」
  - 2つの体験（10/31 と 11/3）は別々に言われたもの。「適応障害がひどかったときに休むのがこわかった」とは言っていない（note 2本目の「はじめに」でも、2つはつなげていない）
  - 直し案（つなげない）：
    ```
    私は前に
    適応障害がひどかったときがあります

    休むのもこわくて
    休んだら罪悪感でいっぱいでした
    ```
    または、つなげてよいかをアカウント主に聞く【要確認：「適応障害がひどかったとき」に休むのがこわかった、とつなげてよいか】
- 該当2：「でも今は思います／休むのは／さぼりじゃなくて回復の時間だって」
  - アカウント主の今の気もちとしては言われていない。ファイルにある【要確認】のとおり、アカウント主に確かめるまで出さない
  - 確かめられないときの直し案（体験にせず、読む人へのことばにする）：
    ```
    休むのは
    さぼりじゃないです
    ```
  - 「回復の時間」は「休めば治る」とまでは言っていないので言い切りではないが、体験として書くならアカウント主の言葉が必要

### 5：みんなに聞いてみる — OK（直すとより安全）
