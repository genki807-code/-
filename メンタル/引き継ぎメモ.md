## 3. 動画の作り方（毎回これ）

### 見た目（アカウント主が決めた・コーポレートロゴ扱い。変えない）
- **0秒の最初のコマから文字が出ている**（フェードなし）。画面1の写真は動かさない。ほかの画面はゆっくり少し寄る
- **テロップ＝白い文字＋黒いふち＋ピンクの帯**（ピンクは RGB 236,122,152）
  - ピンクは**テロップの帯**。動画の背景をピンクにするのではない（背景は写真）
- 文字は小さめ（ほかの画面は約52px）。**画面1だけは大きく（横いっぱい近く・約130〜140px。10/30 アカウント主OK）**。フォントは IPAゴシック
- **句読点（、。）は付けない**（テロップも概要欄も表紙も）。改行・空行で区切る。？・「」・①〜③ は残す
- **行の途中に空白を入れない**（詰める）
- **BGM はなし**（投稿するときも付けない）
- **最初の効果音（オープニング音）はアカウント主が自分で付ける**（10/26 決定）。チームは**音なしで書き出す**。チームが音を入れることはしない

### 手順
1. 台本ができたら、**写真リスト**を作ってアカウント主に渡す（見本：`03_編集/2026-10-30_音疲れ_写真リスト.md`）
   - 写真はできるだけ少なく（同じ写真の別の場所を切り抜いて使い回せる）
   - 無料で商用OKのサイトから（ぱくたそ・写真AC・GAHAG・フリーフォト・Unsplash・Pexels・Pixabay など）。有料サイト（iStock・Getty・Shutterstock・Adobe Stock）は使わない
   - 顔・ロゴ・読める文字が映らないもの
   - アカウント主は**写真リストどおりでなく、自分で選んだ写真を送ってくることもある**。届いた写真に合わせて組み立てる
2. 届いた写真を `03_編集/素材/<日付>_<テーマ>/カット1.jpg`… に保存
3. **`03_編集/2026-10-30_音疲れ_組み立て.py` をコピー**して、次を書きかえて実行
   - `CUTS`（写真・秒数・切り抜き位置・寄り方）、`SCREENS`（テロップ・秒数）、`DUR`、`DARK_START`
   - 顔が入る写真は `CROP` で切り抜く。読める文字は `BLUR` でぼかす
   - **カレンダーなどのただの日付の数字は、弱めのぼかし（`BLUR_R` 3くらい）で形が見えていてよい**（10/29 checker 判断）。ロゴは強めに（`BLUR_R` 20・`FEATHER` 8）。最新の見本は `03_編集/2026-10-31_予定の入れすぎ_組み立て_v3.py`（ぼかしの強さ・切り抜きの上下も指定できる・画面1は大きい文字）
   - 実行：`python3 <組み立て.py> <素材フォルダ> <出力.mp4> <確認画像フォルダ>`（Pillow＋ffmpeg。IPAゴシックがなければ `apt-get install -y fonts-ipafont-gothic`）
4. 確認画像の一覧をアカウント主に見せる → **checker** → 概要欄（句読点なし）も checker → `10_完成/` に完成まとめ
5. ストーリーズ・表紙の画像を作るときは `06_ストーリーズ/2026-10-30_不機嫌_ストーリーズ画像_組み立て.py` を使う（表紙は上下240pxが切れるので、その外に文字を置かない）

### 写真のサイト
- 10/29 の7枚は**ぱくたそ**。毛布の人物写真も含めて使ってOK（アカウント主確認）
- **写真ごとの URL の控えは不要。アカウント主に聞かない**
