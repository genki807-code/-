## 3. 間に合わせるための目安と、作り置き（ストック）の考え方

### アカウント主が決めた作り置きの方針
- **企画と台本は、たくさんストックする。** いまは14本（10/28〜11/10）。台本は script が作成中です（`02_台本/<日付>_<テーマ>_台本.md`）。
- **編集（設計図）は、2本くらいのストック。** editor は、投稿日の近い2本ぶんの設計図を先に作っておきます。
- **10/27 から、冒頭0秒から文字を出す作り方にそろえる。**

### 何をどれくらい先まで用意しておくか（目安）
投稿する日を「当日」としたときの目安です。体調や作業の速さで変わるので、合わなければ直します。

| どれくらい先まで | できていること | だれ |
|---|---|---|
| **多め（いま14本先まで）** | 企画（テーマ・フック案） | research |
| **多め（企画のストックに合わせて）** | 台本（未チェックのストックでよい） | script |
| **2本先まで** | 編集の設計図（カット・テロップ・BGM位置） | editor |
| 2本先まで【要確認：案】 | サムネ案・キャプション（ストーリーズをつけるならストーリーズも） | thumbnail・caption・stories |
| 2日前まで【要確認：案】 | checker の OK → leader の完成まとめ | checker・leader |
| **1日前** | 素材探し・編集・表紙づくり・「0秒チェックリスト」の A・B | アカウント主 |
| 当日 21時 | 自分の手で投稿 | アカウント主 |

- サムネ・キャプション・checker のタイミングは、アカウント主から決まったことではないので、schedule の案です【要確認】。編集の設計図と同じく「2本先まで」にそろえると、checker にまとめて見てもらいやすくなると考えています。
- 台本のストックは、まだ checker を通していない「未チェック」のものです。投稿日が近づいて、編集の設計図を作る段階になったら、checker に回します。
- **10/28（水）は、今日から4日後です。** 編集の設計図・サムネ・キャプション・checker・アカウント主の編集を、10/27 までに終える必要があります。間に合わないときにどうするか（休む／並びを入れかえる など）は、アカウント主が決めてください【要確認】。
- いちばん時間がかかるのは、**アカウント主の編集の作業**と、**checker を通すところ**だと考えています。

### 作り置きの考え方（つづき）
- **作り置きの日**：調子のいい日に、2本ぶんの素材探し・編集をまとめて進めておくと、しんどい日の助けになります。作り置きの日を週の何曜日にするかは【要確認】。
- **同じ作り方をくり返す**：「声なし・文字だけ・約40秒・顔なしの素材・冒頭0秒から文字」の形をそろえると、毎回の編集が軽くなります。
- **ストックが切れた日・体調が悪い日のこと**：休む／ほかの形にする、などを先に決めておくと安心です【要確認】。休んだ日を、次の日に2本出して取り戻す必要はないと考えています。
- **休みの日**：毎日投稿のルールですが、体調に波がある前提で、休みの日を入れるかどうかもアカウント主が決めてください【要確認】。言ってもらえれば、カレンダーに入れます。
- 作り置きしたものも、投稿の前に checker を通します。作り置きは「できたらラッキー」くらいで大丈夫です。

### ストーリーズを毎日つけるか【要確認】（引き続き）
- 10/23・10/27 はリール1本にストーリーズ4枚をつけています。毎日つけると、stories・checker の作業と、アカウント主が1日に何回も出す手間が増えます。
- 毎日つける／リールのシェア1枚だけにする／決めた曜日だけ4枚にする、などから、アカウント主に選んでほしいです。10/24〜10/26 にストーリーズをつけるかも【要確認】です。
