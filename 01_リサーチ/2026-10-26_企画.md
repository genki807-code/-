## 企画（10/26 の1本）

### タイトル：また「いいですよ」と言ってしまう人へ。そのまま使える、やわらかい断り方3つ ◎
（サムネや表紙の大きい文字の案：「断れないのは、／あなたがやさしいから。」など。決めるのは thumbnail 係）

- 形式：リール（声なし・文字だけ・約41秒・顔なし／動画AC）
- だれの：働く20〜30代の繊細さん（通院しながら働いている人も含む）
- どんな悩みに：本当は手がいっぱいなのに、頼まれると「断ったら悪い」「がっかりされたくない」と思って、つい「いいですよ」と引き受けてしまう。週のはじめから仕事を抱えこんで、帰るころにはぐったりしている
- どんな言い方で（型）：**共感（心の声）→ 言い換え → そのまま使えるひと言3つ → 締め・保存のお願い**（流れはこれまでと同じ。中身が「行動」ではなく「口に出すひと言」なのが新しいところ）

#### 冒頭のひとこと（画面1の案）
「今日もまた『いいですよ』って言っちゃった人へ。」
（画面の文字にするときの例：「今日もまた『いいですよ』／って言っちゃった人へ」。文字数・改行は script 係が調整）

#### 流れと見せる場面（すべて顔なし・ロゴや読める文字なし。文言は案なので、script 係が整えてください）

| 流れ | 画面の文字のイメージ | 見せる場面（動画ACで探すもの） |
|---|---|---|
| フック | 今日もまた「いいですよ」って言っちゃった人へ | 積み木（木のブロック）を1つずつ高く積んでいく手元。少しずつグラつく |
| 共感（心の声） | 本当は手いっぱいなのに、断ったら悪い気がして | 透明なグラスに水が、ふちぎりぎりまで注がれていく（あふれる直前で止まる。あふれる場面は使わない） |
| 言い換え | 断れないのは、相手を大事にできるから | 手のひらに、小さな花（または小さな苗）をそっとのせている手元 |
| 言い換え | でも、あなたの時間も同じくらい大事です | 同じカットのまま（文字だけ入れ替え） |
| ひと言① | ①すぐに返事をしない：「確認してから、お返事してもいいですか？」 | 砂時計の砂が落ちていく（時間をもらう、のイメージ） |
| ひと言② | ②できる分だけ伝える：「ここまでなら、できそうです」 | パンやお菓子を手で半分に分ける手元（全部ではなく一部、のイメージ。商品名・包装の文字なし） |
| ひと言③ | ③順番を相手にたずねる：「今の作業とどちらを先にしたらいいですか？」 | 小石やビー玉を、手で1つずつ順に並べていく手元 |
| 締め | 今日の「いいですよ」も、がんばった証拠です | 玄関の棚やトレイに、鍵をそっと置く手元（一日が終わったイメージ。キーホルダーのロゴ・文字なし） |
| 保存のお願い | 明日、頼まれたときのために保存してくださいね | 鍵のカットのまま、ゆっくり暗くなって終わる |

- ひと言①〜③は「」の中が、**そのまま口に出して使えるひと言**です。画面の文字が長くなる場合は、見出し（「すぐ返事をしない」など）を外し、「」のひと言だけを出してください（ひと言が主役。1秒に4〜5文字の決まりを優先）。
- **使わない映像**（10/23・10/24・10/25・10/30 で使用）：毛布・ベッド・カーテン・スマホの手元・マグカップ・観葉植物・キーボード・机の書類・廊下の足元・ハンドクリーム・夜の街の灯り・窓の外の空（曇り→晴れ／夕暮れ）・洗濯物・シャツ・アイロン・書類に書き出す手元・ノート・うずくまる人・胸に手を当てる人・揺れる草・夕焼け・カレンダー・付箋・夜の窓の明かり・夜の湖・椅子の服やバッグ・本とお菓子のテーブル・間接照明。**職場の机まわり（パソコン・書類）も 10/30 と重なるので避けています。**
- 合う素材がないときの入れ替え例（顔・ロゴなしに限る）：積み木 → 積み重なった小さな箱／グラスの水 → ピッチャーで注ぐ水／砂時計 → 小さな置き時計の秒針（文字盤の文字・ブランド名が読めないもの）／鍵 → 玄関でそろえて脱いだ靴（ロゴなし）。

#### かぶらないように気をつけたところ
- **コツ・言い回し**
  - 10/23：休む日と決める／「疲れたから」で十分／「今は回復中」とつぶやく
  - 10/24：書き出してノートを閉じる／友だちが同じ返事をしたら？／手を動かす
  - 10/25：朝やることを1つに／服と持ち物をそろえる／明日の夜の楽しみ
  - 10/30：少し席を離れる／温かい飲み物／心の中で「これは私の係じゃない」
  - → 今回は**相手に向けて口に出すひと言**なので、どれとも形が違います。「〜の係じゃない」「担当じゃない」「〜で十分」「〜じゃないんです」の言い回しは使わないでください。
- **締めの言い回し**：「休んで大丈夫」（10/23）・「よく乗りきりましたね」（10/24）・「ゆっくり始めればいい」（10/25）・「その優しさ、まず自分に使ってね」（10/30）と重ならないよう、「がんばった証拠」の方向にしました。
- **保存のお願い**：「〜日に見返せるよう、保存してくださいね」（10/23・10/30）・「〜夜のために、保存しておいてくださいね」（10/24）・「来週の日曜の夜のために」（10/25）と言い回しが近くなりやすいので、「明日、頼まれたときのために」のように **場面（頼まれたとき）** を入れて変化をつけてください。
- **10/25 とのつながり**：10/25 は「日曜の夜、明日の朝にそなえる」話。10/26 は「月曜が終わった夜、明日からすぐ使えるひと言」の話で、向きが続きながら中身は別です。月曜の朝・出勤のつらさの話は入れないでください（10/25 と重なるため）。

#### 保存したくなる理由
- 頼まれたその場で見返して、**そのまま口に出せるひと言（テンプレート）** が3つある（保存されやすいとされる型。#9・#10 の検索結果の要約から）。
- 月曜の夜に見て、翌日の火曜からすぐ使える。頼まれごとは毎週くり返すので、見返す理由がはっきりしている。
- 「断れないのは、相手を大事にできるから」「あなたの時間も同じくらい大事」という、言われたかったひと言がある。

#### 注意点
- **「断るべき」「断れないのはだめ」と押しつけない。** 引き受けることを選んでもいい、という立ち位置にする（締めの「がんばった証拠」もその意味）。キャプションで「全部断らなくても大丈夫。言えそうなものを1つだけで」のような一文を入れるかは caption 係と相談。
- **「これで角が立たない」「必ずうまくいく」と言い切らない。** 「やわらかく伝えやすくなるかもしれません」の言い方にする。職場や相手によって合う言い方は違う、という前提で。
- 立場上どうしても断れない場面（上司からの指示など）もあるので、ひと言③は「断る」ではなく「順番を相談する」形にしています。断れないことを責める読まれ方にならないよう注意。
- 「断れないのは HSP だから」「繊細さんの特徴」などと決めつけない。病気・症状のように言わない。
- 通院・体調のことを職場に伝えるよう勧める内容は入れない（言うかどうかは本人が決めること）。
- 頼まれごとが多すぎる・断ると強く責められるなど、ハラスメントのようにつらいときのために、キャプションに「ひとりで抱えこまず、信頼できる人や相談できる先に話してみてください」「つらさが続くときは、医師や専門の相談窓口に相談してくださいね」を添える。相談窓口の名前・電話番号を書くなら【要確認】（公式情報で確かめてから）。
- グラスの水は**あふれる場面を使わない**（不安をあおらないように。ぎりぎりで止まる・注ぐのをやめる場面まで）。
- ひと言②（できる分だけ伝える）は、`2026-10-30_企画.md` の #5（断り方の記事）で紹介されていた「代替案を添える」方向と近いです。**記事の言い回しは使わず、言葉は script 係が新しく考えてください。** 台本ができたら、checker で似すぎていないか確認【要確認】。
- 研究・数字は使わない（出典がないため）。「月曜は頼まれごとが多い」なども数字では書かない。
- アカウント主の体験（「私も断れなくて〜」など）は入れない前提【要確認】。
